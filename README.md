# Exercícios e Estudos em Linguagem C 🚀

Repositório dedicado ao aprendizado e prática da linguagem C, cobrindo desde a sintaxe básica até conceitos de gerenciamento de memória e estruturas de dados.

## 📌 Objetivos
- Dominar os fundamentos da linguagem C (tipagem, controle de fluxo, funções).
- Compreender o processo de compilação com `gcc`.
- Praticar conceitos avançados como ponteiros, alocação dinâmica de memória e *structs*.
- Registrar a evolução prática através de exercícios e pequenos projetos.

## 🛠️ Tecnologias e Ferramentas
- **Linguagem:** C
- **Compilador:** GCC (GNU Compiler Collection)
- **Ambiente de Desenvolvimento:** Visual Studio Code / Linux
- **Controle de Versão:** Git & GitHub
